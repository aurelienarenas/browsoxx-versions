# Browsoxx

Le navigateur qui flotte au-dessus de tes pages, avec **Bro**, le chat qui t'aide à naviguer.

Site : https://aurelienarenas.github.io/browsoxx-versions/

## Installer

1. Ouvre la [dernière version](https://github.com/aurelienarenas/browsoxx-versions/releases/latest).
2. Télécharge `Browsoxx-Setup-<version>.exe` et lance-le. Pas besoin d'être administrateur.

Windows peut afficher « Windows a protégé votre ordinateur » : l'installeur n'est pas signé
numériquement. Clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Il faut Windows 10 (version 1809 ou plus récente) ou Windows 11, en 64 bits. L'installeur ajoute le
moteur Microsoft Edge WebView2 s'il manque.

## Mises à jour

Une fois par jour, Browsoxx regarde ici si une nouvelle version existe, et Bro te la propose. Rien ne
s'installe sans ton accord. Chaque version est signée : Browsoxx refuse un fichier modifié.

## Contenu de chaque version

- `Browsoxx-Setup-<version>.exe` : l'installeur.
- `latest.json` et `latest.json.sig` : la description de la version et sa signature, lues par Browsoxx.
- `LICENCES-TIERCES.txt` : les licences des composants repris.
